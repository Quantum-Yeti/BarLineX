# BarLineX

A lightweight Android application for generating, saving, and scanning QR codes and Code 128 barcodes.

## Features

- Generate QR codes and Code 128 barcodes from text or numeric input.
- Preview barcodes in real time as you type.
- Save generated barcodes as image files.
- Copy barcode content to the clipboard.
- Share generated barcodes.
- View barcodes in an enlarged preview.
- Save and reopen previously generated barcodes.
- Decode a barcode's data.
- Export barcode data as a CSV file.

## Tech Stack

- **Language:** Java
- **Platform:** Android SDK
- **UI:** XML Layouts, Material Components
- **Architecture:** MVVM (Android ViewModel)
- **Database:** Room
- **Barcode Generation:** ZXing
- **Text Recognition:** Google ML Kit
- **Camera:** CameraX

## Requirements

- Android Studio
- Android SDK
- Java-compatible Android development environment

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Quantum-Yeti/BarLineX.git
   ```
2. Open the project in Android Studio.
3. Allow Gradle to sync and download the required dependencies.
4. Build and run the application on an Android device or emulator.
